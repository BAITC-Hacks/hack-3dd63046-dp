# FAQ-бот репетиции HackAlem AI

Консольный бот отвечает на пять заранее известных вопросов о репетиции: время сдачи, команда, выбранный трек, место сдачи и призы. Он читает пары вопрос–ответ из `faq.txt`, выделяет ключевые слова (включая распространённые словоформы) и возвращает ответ к наиболее похожему вопросу. Если совпадений нет или вопрос одинаково похож на несколько тем, бот печатает: «не знаю».

## Запуск

Нужен Node.js 18 или новее. Зависимости устанавливать не требуется.

```powershell
node bot.js
```

Введите вопрос в строке с `>`. Для завершения работы введите `выход`.

Примеры:

```text
> Когда нужно сдать решение?
Загрузите решение в репозиторий команды до окончания хакатона.

> Есть ли призы?
Нет, это репетиция, поэтому призов нет.

> Какая сегодня погода?
не знаю
```

## Проверка

```powershell
node bot.test.js
```

В `faq.txt` каждая строка содержит один вопрос и один ответ, разделённые табуляцией. При добавлении новой темы можно добавить новую пару; дополнительные синонимы для неё при необходимости задаются в `TOPIC_KEYWORDS` в `bot.js`.

# FAQ-бот для репетиции

Консольный бот для пяти известных вопросов о репетиции: время, команда, трек, сдача и призы. Он не использует RAG или внешние библиотеки: читает `faq.txt`, сравнивает ключевые слова, синонимы и основы слов. Если надёжного совпадения нет либо темы равны по релевантности, отвечает `не знаю`.

## Запуск

Нужен Node.js 18 или новее. Установка зависимостей не требуется.

```powershell
node bot.js
```

Задайте, например, «Во сколько начало?», «Кто участвует?» или «Будут награды?». Для выхода используйте `выход` либо `/exit`.

## Команды

| Команда | Действие |
| --- | --- |
| `/help` | краткая справка |
| `/topics` | вывести пять известных вопросов |
| `/examples` | показать примеры формулировок |
| `/why <вопрос>` | показать выбранную тему, ключевые слова и оценку совпадения |
| `/stats` | показать статистику диалога |
| `/reload` | повторно прочитать `faq.txt` без перезапуска |
| `/exit` | завершить чат |

## Данные и проверка

В `faq.txt` ровно пять строк с полями `ID`, вопрос и ответ, разделёнными табуляцией. `ID` связывает строку с набором ключевых слов в `bot.js`; вопросы и ответы можно менять без изменения кода. Проверьте бот командой:

```powershell
node bot.test.js
```

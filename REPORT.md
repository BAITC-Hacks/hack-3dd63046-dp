# Отчёт по FAQ-боту

## Результат

Доработан терминальный FAQ-бот на Node.js без внешних зависимостей. Он отвечает на пять тем репетиции: время, команда, трек, сдача и призы. Данные хранятся в `faq.txt` и валидируются при загрузке.

## Реализованные возможности

- поиск по ключевым словам, синонимам и основам русских слов;
- безопасный ответ `не знаю`, если нет совпадений или несколько тем равны по релевантности;
- команды `/help`, `/topics`, `/examples`, `/why <вопрос>`, `/stats`, `/reload` и `/exit`;
- отображение выбранной темы, совпавших слов и оценки через `/why`;
- статистика известных и неизвестных ответов за текущий сеанс;
- автоперезагрузка `faq.txt` без перезапуска программы;
- автотесты ключевых сценариев и проверка формата FAQ.

## Проверка

Запуск тестов на машине с Node.js 18+:

```powershell
node bot.test.js
```

В текущем окружении Node.js не установлен, поэтому выполнена статическая проверка: в `faq.txt` пять уникальных тем, все строки имеют корректные поля, а тесты покрывают ответы, неизвестный вопрос, равную релевантность и команды.
